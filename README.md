# Junior Business Analyst Portfolio — Chan Baojeff (Career Changer, Self-Taught)

> **Disclosure:** Every project in this portfolio is an independent case study built around a fictional client, *QuickKlinik*, created for learning purposes. It is not real client work.

## About me

I'm still on the self-learning route to becoming a Junior Business Analyst. This portfolio demonstrates the four things employers test: understanding a business problem, asking the right questions, documenting clearly, and getting people to agree. Built over 8 weeks (~10–12 hrs/week) using free tools only (draw.io, Figma free, Google Sheets, Notion).

## The fictional client: QuickKlinik

A small fictional online clinic-booking platform in Malaysia. Patients book GP appointments through a web app; clinics manage schedules on a lightweight admin panel. See the [company profile](01-process-improvement/README.MD).
